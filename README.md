# Walkman📼

Bringing back the **old-school Walkman vibes** straight to your browser!
(_Inspo to the 2025 updated version_)


## Features

- **Intuitive UI** – Clean and minimal, inspired by classic designs  
- **Smooth Animations** – Buttons and controls that feel satisfying to use   



## Tech Stack

> **Built using the classics!**  

- **HTML5** – The structure holding everything together  
- **CSS** – For sleek, pixel-perfect styling  
- **JavaScript** – Powers the player controls  



## How to Run

1) Clone this repo:  
```sh
git clone https://github.com/TamizhSK/Walkman.git
cd Walkman
```

2️) Open index.html in your browser and there you go!
